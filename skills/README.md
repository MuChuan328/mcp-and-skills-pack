# 技能清单

> 按「什么时候用哪个」组织，避免拿到任务就乱开工具。名称是通用叫法，具体实现按自己环境替换。

## 观察 / 取证

| 技能 | 用途 | 触发词 |
| --- | --- | --- |
| `browser-observe` | 打开页面、抓网络、看控制台、定位加密入口 | 抓包、找接口、看请求 |
| `env-fingerprint` | 对比浏览器环境，判断是否被指纹检测 | 环境检测、指纹、风控 |
| `miniapp-debug` | 小程序/WebView CDP 调试 | 小程序、WMPF、62000 端口 |

## 静态分析

| 技能 | 用途 | 触发词 |
| --- | --- | --- |
| `android-static` | jadx/apktool 反编译、定位类与方法 | 反编译、APK、分析代码 |
| `android-unpack` | 脱壳、加固识别、DEX 提取 | 脱壳、加固、360/梆梆/乐固 |
| `native-reverse` | so 分析、符号恢复、OLLVM 去混淆 | so、native、混淆 |

## 动态调试

| 技能 | 用途 | 触发词 |
| --- | --- | --- |
| `frida-hook` | Hook Java/Native、改返回值、打印参数 | Frida、hook、注入 |
| `x64dbg-debug` | Windows 调试、断点、内存与调用栈 | 调试、断点、寄存器 |
| `js-debug` | 浏览器断点、调用栈、evaluate | JS 逆向、断点、加密函数 |

## 协议与复现

| 技能 | 用途 | 触发词 |
| --- | --- | --- |
| `protocol-reverse` | 抓包 → 定位 → 签名还原 → 本地复现 | 协议、签名、加密参数 |
| `captcha-analysis` | 验证码链路分析（授权环境） | 验证码、滑块、点选 |
| `api-replay` | 用 Python 复现请求并做稳定性验证 | 复现、脚本、接口 |

## 工程与交付

| 技能 | 用途 |
| --- | --- |
| `code-generation` | 生成分析脚本、Hook 模板、测试用例 |
| `doc-writing` | 把分析过程写成可复用的笔记 |
| `env-check` | 检查 jadx/apktool/frida/adb 等依赖 |

## 使用原则

1. **先取证再动手**：抓包/日志/样本齐了再开工具；
2. **最小实验**：一次只改一个变量，能复现再继续；
3. **证据优先**：结论要能指向具体日志、请求或反编译片段；
4. **可回滚**：修改样本前先备份，保留原始与派生文件。
